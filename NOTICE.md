## Data model derived at build time

- `data_model/model_subset.yaml` names the tables and columns used from the `media_broadcasting` v2 MVM model in
  `databricks-industry-solutions/lakehouse-industry-data-models` (Databricks License).
- The model file itself is not vendored. `data_model/build_ddl.py` downloads it at a pinned commit into a
  temporary folder when you run `make data`. Only the table and column names, and the DDL built from them,
  come from the model. The synthetic data is generated by this lab's own code.
